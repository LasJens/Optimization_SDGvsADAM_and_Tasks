# Optimization Methods — Tasks & Project

This repository contains my coursework and project materials for the **Optimization Methods** course. It includes Jupyter notebooks with practical tasks and the final project.

## Contents

### Course Tasks (Jupyter Notebooks)

- **1_stochastic.ipynb** — stochastic optimization methods
- **2_NN.ipynb** — optimization in neural networks
- **2_anomalies.ipynb** — anomaly detection tasks
- **3_big_models.ipynb** — optimization for large-scale models
- **4_ADMM.ipynb** — ADMM
- **5_continuous.ipynb** — continuous optimization problems
- **conditional.ipynb** — conditional optimization tasks
- **newton_quasinewton.ipynb** — Newton and quasi-Newton methods
- **proximal.ipynb** — proximal methods
- **subgrad.ipynb** — subgradient methods
